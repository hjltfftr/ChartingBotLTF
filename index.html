Broker Summary (Pluang)

Klik "Ambil Broksum" untuk memuat. Stock ID Pluang dicari otomatis dari kode saham (bisa diisi manual), lalu diingat browser.
biquote mengambil harga dari feed MetaTrader 5 sebuah broker, jadi bisa sedikit berbeda dari TradingView. Simbol berlaku untuk biquote dan Twelve Data; Binance selalu PAXG/USDT (token emas). Yahoo Finance dipakai untuk saham Indonesia/IHSG (kode pakai akhiran .JK, mis. BBCA.JK, atau ^JKSE untuk indeks) maupun saham/indeks global lain — tanpa API key, tapi tanpa live tick/WebSocket (refresh tiap ~30 detik) dan candle 4h didekati dari agregasi candle 1h karena Yahoo tidak punya interval 4h asli. Stooq adalah alternatif saham Indonesia kalau Yahoo gagal/diblokir jaringan — gratis tanpa API key, tapi HANYA data harian (timeframe 1d). Kedua sumber ini mencoba lewat beberapa proxy CORS otomatis dengan timeout 8 detik per percobaan; kalau tetap gagal semua kemungkinan jaringan/ISP memblokir domain-domain tersebut. Candle mingguan di biquote dihitung dari candle harian. Marker pola candle hanya untuk candle yang sudah tutup: biru muda = bullish, merah muda = bearish, abu-abu = netral. Di tabel: Candle Run = candle yang sedang berjalan, Candle Cls = candle sebelumnya yang sudah tutup (hijau bullish, merah bearish, oranye netral). Pluang: saham IDX saja, timeframe 1h/4h/1d/1w plus 5m/15m/30m (hanya data hari ini, tanpa 1m); kode saham otomatis dipetakan ke Stock ID Pluang untuk URL .../ohlc/<stockId>, 4h dibentuk dari candle 1 jam (2 candle/hari). Gabungan: histori panjang dari Yahoo, candle terbaru disambung dari Pluang yang real-time, jadi grafik tidak tertinggal 10–15 menit; harga dipoll tiap ~8 detik dari Pluang. Kalau Pluang gagal / simbol indeks / timeframe 1m, otomatis hanya Yahoo. Bukan saran investasi.

Pola Chart Klasik

1. Data

Batasi kode (opsional, pisah spasi/koma). Kosong = semua saham IDX di daftar.
⏱ Data Yahoo Finance tertunda sekitar 10–15 menit dari harga pasar sebenarnya, jadi hasil screening live juga ikut tertunda. Untuk entry intraday, cek harga real-time di aplikasi sekuritas Anda.
Belum ada data. Klik "Ambil data" (sumber: Yahoo Finance lewat proxy di pengaturan Charting).

2. Filter (semua yang dicentang harus lolos)

Isi modal (Rp) yang mau dipakai entry — cocok juga buat scalping modal kecil. Screener otomatis buang saham yang (1) harganya kebesaran sampai modal itu tidak cukup beli 1 lot, dan (2) terlalu tipis volumenya dibanding modal, supaya yang lolos hanya saham yang gampang keluar-masuk cepat dengan modal segitu. Kosongkan kalau tidak mau difilter berdasarkan ini — filter lain tetap jalan seperti biasa.
Tempel logika filter di sini. Variabel: c = array candle {time,open,high,low,close,v}; SCH = {sma, ema, ma(arr,n), closes(c)}. Kembalikan true/false, teks info, atau {pass:true, info:'...'}.
