biquote mengambil harga dari feed MetaTrader 5 sebuah broker, jadi bisa sedikit berbeda dari TradingView. Simbol berlaku untuk biquote dan Twelve Data; Binance selalu PAXG/USDT (token emas). Yahoo Finance dipakai untuk saham Indonesia/IHSG (kode pakai akhiran .JK, mis. BBCA.JK, atau ^JKSE untuk indeks) maupun saham/indeks global lain — tanpa API key, tapi tanpa live tick/WebSocket (refresh tiap ~30 detik) dan candle 4h didekati dari agregasi candle 1h karena Yahoo tidak punya interval 4h asli; jika gagal dimuat karena CORS, coba lagi atau host sendiri lewat proxy. Candle mingguan di biquote dihitung dari candle harian. Marker pola candle hanya untuk candle yang sudah tutup: biru muda = bullish, merah muda = bearish, abu-abu = netral. Di tabel: Candle Run = candle yang sedang berjalan, Candle Cls = candle sebelumnya yang sudah tutup (hijau bullish, merah bearish, oranye netral). Bukan saran investasi.
